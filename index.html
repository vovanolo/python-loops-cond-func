1. Умови: if, elif, else

Умови — це спосіб сказати програмі: «якщо щось правда — зроби це, інакше — зроби інше». Без умов програма завжди робить одне й те саме.

Уяви охоронця біля входу в кіно на фільм 16+. Його інструкція:

Інструкція охоронця ЯКЩО вік відвідувача ≥ 16 — пропусти. ІНАКШЕ — скажи «вибачте, не можна».

1.4 elif — коли варіантів більше двох

Часто потрібно перевірити не одне, а кілька питань по черзі. Наприклад, оцінка за балами:

score = 78

if score >= 90:
    print("Відмінно")
elif score >= 75:
    print("Добре")
elif score >= 60:
    print("Задовільно")
else:
    print("Незадовільно")
Добре

elif = «else if» = «інакше, якщо». Як це працює — дуже важливо:

  1. Python перевіряє умови зверху вниз, по черзі.
  2. Як тільки знайшлася перша True — виконується її блок, а решта пропускається повністю.
  3. Якщо жодна не спрацювала — виконується else (якщо він є).
Чому 78 дало «Добре», а не «Задовільно»? Бо 78 ≥ 75 — це True, і Python зупинився на цій гілці. Він навіть не перевіряв score >= 60, хоча вона теж правдива. Тому порядок умов має значення.

Розгорни, щоб побачити, що буде, якщо переплутати порядок:

Неправильний порядок умов 
score = 95
if score >= 60:
    print("Задовільно")    # 95 >= 60 → True → виконується ЦЕ
elif score >= 75:
    print("Добре")         # не перевіряється
elif score >= 90:
    print("Відмінно")      # не перевіряється
Задовільно

Студент із 95 балами отримав «Задовільно». Умови з >= треба писати від більшого до меншого.

2.5 Цикл while — «поки правда»

count = 3
while count > 0:
    print(count)
    count = count - 1
print("Старт!")
3 2 1 Старт!

Алгоритм роботи while:

  1. Перевірити умову (count > 0).
  2. Якщо True — виконати тіло, повернутись до кроку 1.
  3. Якщо False — вийти з циклу і йти далі.
Найнебезпечніша помилка: нескінченний цикл Якщо забути рядок count = count - 1, умова count > 0 ніколи не стане False, і програма «зависне», друкуючи 3 без кінця. Зупинити її можна комбінацією Ctrl+C.
Правило: у тілі while має бути щось, що наближає умову до False.

Змінна, створена всередині функції, живе лише всередині неї. Зовні її не видно. Це називається локальна змінна.

А якщо всередині функції створити змінну з таким самим іменем, як зовні? Створиться нова, окрема локальна змінна, а зовнішня не зміниться:

Розв'язок 
def is_strong(password):
    if len(password) < 8:
        return False
    has_digit = False
    has_upper = False
    for ch in password:
        if ch.isdigit():
            has_digit = True
        if ch.isupper():
            has_upper = True
    return has_digit and has_upper

print(is_strong("abc"))          # False
print(is_strong("Password1"))    # True
